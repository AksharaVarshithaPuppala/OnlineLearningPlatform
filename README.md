# LearnSpace – Online Learning Platform

LearnSpace is an online learning platform developed to provide students with an easy way to explore courses and access learning content.

## Live Demo

[Visit LearnSpace](https://learnspace-frontend-m0zh.onrender.com)

## Project Repository

[GitHub Repository](https://github.com/AksharaVarshithaPuppala/OnlineLearningPlatform)

## Technologies Used

- **Frontend:** React JS
- **Backend:** Spring Boot, Spring MVC
- **Database:** MySQL
- **Deployment:** Render
- **Database Hosting:** Aiven

## Features

- View available courses
- Search for courses
- View course information
- Interactive quizzes
- Team details displayed on the homepage
